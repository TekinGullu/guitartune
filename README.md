# GuitarTune — gizlilik politikası

Tek amaci var: Google Play'in zorunlu tuttugu, herkese acik gizlilik politikasi
sayfasini yayinlamak. Uygulamanin kaynak kodu burada degil.

GitHub Pages ile yayinlanir; Settings > Pages > Source: main / (root).

Metnin ana kopyasi uygulama deposunda `docs/privacy.html` dosyasinda durur.
Degistirdiginizde iki yeri de guncelleyin.
